# Speech Recognition and Translator

## About the Project

Speech Recognition and Translator is a Python-based project that records speech through a microphone, converts spoken words into text, and translates the recognized text into a language selected by the user.

The program uses speech recognition technology and an online translation service to make communication easier.

## Features

- Voice recording through a microphone.
- Automatic speech recognition.
- Speech-to-text conversion.
- Translation into different languages.
- Custom translation language selection.
- Audio recording saved in WAV format.

## Technologies Used

- Python
- SoundDevice
- NumPy
- SciPy
- SpeechRecognition
- Google Translate

## How to Run

1. Clone or download this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder.
4. Install the required libraries:

```bash
pip install -r requirements.txt
```

5. Make sure your microphone is connected and accessible.
6. Run the program:

```bash
python audio.py
```

## How to Use

1. Run the program.
2. Enter the language code for the desired translation (for example, `en` for English or `es` for Spanish).
3. Speak into your microphone when prompted.
4. Wait for the program to finish recording.
5. The program displays the recognized speech and its translation.
